# DIYOUTLET 홈페이지

다이샵아울렛(DIYOUTLET)을 위한 반응형 브랜드 랜딩페이지입니다. 순수 HTML, CSS, JavaScript로 제작되어 별도 빌드 없이 바로 열 수 있습니다.

## 파일 구성

- `index.html` — 사이트 문구와 섹션 구조
- `styles.css` — 색상, 레이아웃, 반응형 디자인
- `script.js` — 모바일 메뉴와 스크롤 등장 효과
- `assets/hero.png` — 메인 이미지
- `assets/product01.png` ~ `product04.png` — 대표 제품 이미지

## 수정 방법

1. 문구는 `index.html`에서 바로 수정합니다.
2. 이미지는 `assets` 폴더 안 파일을 같은 이름으로 교체합니다.
3. 네이비·옐로우 색상은 `styles.css` 맨 위의 `:root` 변수에서 수정합니다.
4. 스마트스토어 버튼 주소는 `index.html`에서 `href="#contact"`를 실제 주소로 교체합니다.

## 실행 방법

`index.html` 파일을 브라우저로 열면 됩니다.
